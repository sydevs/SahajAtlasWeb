# Cloudflare Pages serves this from the build output, like _redirects and _headers.
# NOTE it lands in BOTH: `pnpm build` copies public/ into dist/ (the `sahajatlas` app)
# and `pnpm ladle:build` copies it into build/ (the `sahajatlas-design` playground), so
# this one file is the policy for both projects. That is wanted — a component playground
# is no more a search surface than the app is — but it means the runbook at the bottom
# opens the playground too.
#
# ---------------------------------------------------------------------------------
# THE POLICY, and the one place it is written down (issue #106).
#
# Search is owned by WeMeditate and the other embedding sites. This deployment is the
# standalone build of an EMBEDDABLE widget: every canonical link and every share URL it
# emits already points at SahajCloud's `webUrl` — the WeMeditate surface — so a
# sahajatlas.* URL in a result page is a duplicate of somebody else's page, not a
# destination of its own. Hence: resist direct indexing.
#
# Three signals carry that, and they are NOT interchangeable:
#   - this file       — do not fetch.
#   - X-Robots-Tag    — do not index, on every URL (public/_headers).
#   - <meta robots>   — do not index, without depending on Cloudflare (index.html).
#
# THE INTERACTION THAT MATTERS. `Disallow` means "do not fetch", not "do not index" — so
# a compliant crawler that never fetches a page also never sees the `noindex` we serve on
# it. The two do not stack; the weaker signal hides the stronger. Residual risk, accepted
# deliberately: a URL linked from an external page can still be listed URL-only, with no
# title or snippet.
#
# RUNBOOK. If sahajatlas.* is ever FOUND in an index, relax this file rather than
# tightening it — swap `Disallow: /` for `Allow: /` so the crawler can fetch the page,
# read the noindex and drop the entry, then restore this once it is gone. Remember that
# doing so opens sahajatlas-design.pages.dev for the same window (see the note above).
# ---------------------------------------------------------------------------------
User-agent: *
Disallow: /

# Link-preview scrapers are not search engines, and they are the reason the OG tags and
# JSON-LD stay in the standalone head. ShareView hands the share sheet
# `event.webUrl ?? window.location.href`, so an event with no canonical link —
# unpublished or gated — is shared as a sahajatlas.* URL; the address bar is
# copy-pasteable regardless. Each of these honours robots.txt, so the blanket Disallow
# above would have left us serving preview metadata that nothing was allowed to fetch.
# None of them feeds a search index, so allowing them costs nothing against the policy.
#
# One group, many tokens: the format applies a group's rules to every User-agent line in
# it. Slack appears twice because the unfurl bot's product token is
# Slackbot-LinkExpanding and group selection matches the token, not a prefix of it.
User-agent: facebookexternalhit
User-agent: Twitterbot
User-agent: LinkedInBot
User-agent: Slackbot
User-agent: Slackbot-LinkExpanding
User-agent: WhatsApp
User-agent: TelegramBot
User-agent: Discordbot
Allow: /
